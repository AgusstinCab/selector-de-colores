# Coloors — Generador de paletas

Generador de paletas de colores, inspirado en Coolors. Con la barra espaciadora se genera una paleta
nueva; cada color se puede bloquear para conservarlo y copiar su código hexadecimal al portapapeles.

## Qué incluye
- Generación de paleta con la tecla **Espacio**
- Bloqueo individual de colores
- Copia del código hex con un clic
- Estado global con **Zustand**

## Stack
`React` · `Vite` · `Tailwind CSS` · `Zustand`

## Ejecutar
```bash
pnpm install   # o npm install
pnpm dev       # o npm run dev
```
